🔥 Firebase 설정

아래에 Firebase 프로젝트 설정 값을 입력하고 저장 및 연결을 클릭하세요.
설정 값은 이 기기에 저장됩니다 (localStorage).

📖 Firebase 설정 방법
  1. Firebase Console에서 새 프로젝트 생성
  2. Realtime Database → 데이터베이스 만들기 → 테스트 모드로 시작
  3. 프로젝트 설정(⚙️) → 일반 → 내 앱 → 웹 앱 추가 (</>)
  4. 앱 등록 후 표시되는 firebaseConfig 값을 위 입력칸에 붙여넣기
  5. 저장 및 연결 클릭 → 실시간 동기화 시작

🚀 처음 시작하기

📂 파일 열기

1
파일을 받으면 더블클릭하여 크롬(Chrome) 브라우저로 엽니다.
2
화면 상단에 🔥 실시간 동기화 중이 표시되면 자동으로 연결된 것입니다.
3
연결이 안 된다면 ⚙️ Firebase 설정 탭에서 저장 및 연결 버튼을 눌러주세요.
💡 인터넷이 연결된 상태에서 사용해야 실시간 공유가 됩니다.

✏️ 데이터 입력 권한

파일을 열면 누구나 내용을 입력·수정·삭제할 수 있습니다. 저장 버튼을 누르는 즉시 모든 사용자 화면에 실시간으로 반영됩니다.

🏠 오늘 탭

오늘 화면에서 볼 수 있는 것

  • 날짜 배너 — 오늘 날짜·요일이 크게 표시되고, 오늘 등록된 일정·복무·수행평가 건수를 보여줍니다.
  • 오늘 일정 — 월중계획 중 오늘에 해당하는 행사
  • 오늘 복무 — 오늘 출장·연가 등 복무 중인 관리자
  • 이번 주 수행평가 — 오늘 기준 전후 7일 내 수행평가 일정
  • 이번 주 핵심 업무 — 오늘 요일의 부서별 주간업무
💡 별도 조작 없이 열면 자동으로 오늘 내용이 표시됩니다.

📋 주간업무

📌 주간업무란?

각 부서가 2주 후 업무 계획을 미리 입력하는 공간입니다. 한 주는 일요일부터 시작됩니다. 탭 상단에 입력 대상 날짜 범위가 자동으로 표시됩니다.

➕ 부서 업무 입력하기

1
우측 상단 ✏️ 부서업무 입력 버튼을 클릭합니다.
2
드롭다운에서 소속 부서를 선택합니다.
3
월~금 각 칸에 해당 요일 업무를 입력합니다.
4
저장 (실시간 반영) 버튼을 누릅니다.
💡 같은 방법으로 다시 입력하면 기존 내용이 수정됩니다.

2

3
저장 버튼을 누릅니다.
💡 < > 버튼으로 다른 달의 수행평가를 확인할 수 있습니다. 항목을 클릭하면 수정·삭제가 가능합니다.
❓ 자주 묻는 질문
Q. 데이터가 안 보여요.
상단에 🔥 실시간 동기화 중이 표시되는지 확인하세요. 표시가 안 되면 ⚙️ Firebase 설정 탭에서 저장 및 연결 버튼을 클릭하고 새로고침(F5)합니다.
Q. 내가 입력한 것이 다른 사람 화면에 안 보여요.
저장 버튼을 누른 뒤 상대방이 화면을 새로고침(F5) 하거나 잠시 기다리면 반영됩니다. 인터넷 연결 상태를 확인해 주세요.
Q. 실수로 일정을 삭제했어요.
삭제된 데이터는 복구가 어렵습니다. 다시 추가해 주세요. 중요한 데이터는 주기적으로 메모해 두시길 권장합니다.
Q. 새 파일을 받으면 기존 데이터가 사라지나요?
아니요. 데이터는 인터넷(Firebase)에 저장되어 있으므로 파일이 바뀌어도 데이터는 그대로 유지됩니다.
Q. 스마트폰이나 태블릿에서도 사용할 수 있나요?
네, v1.7부터 태블릿·스마트폰 반응형을 완전 지원합니다. 크롬 브라우저로 파일을 열면 화면 크기에 맞게 자동으로 레이아웃이 조정됩니다. 일정 추가·수정·실시간 공유도 모바일에서 동일하게 동작합니다. 단, 주간업무 표처럼 가로가 긴 화면은 좌우 스크롤로 확인하세요.
